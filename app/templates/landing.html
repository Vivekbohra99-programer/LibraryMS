Eager vs Lazy Loading

Lazy (what this app does): book lists never decompress anything. Descriptions and covers stay compressed in memory until one book is opened.

Eager loading would decompress every description and cover up front. The exact memory difference is measured on demand by the benchmark on the Performance page, so no numbers are claimed here.
